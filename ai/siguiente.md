# Sin tarea asignada en esta rama

Las tareas se asignan en la **rama de cada tarea** (por ejemplo `00-reconocimiento`, `01-iniciar-sesion`).
Claude Chat crea la rama desde `develop` y escribe aquí la tarea. Si estás leyendo esto desde `main` o `develop`, cambia a la rama de tarea que te indique el usuario:

```bash
git fetch origin
git checkout <rama>
git pull
```

Ver `ai/conocimiento/02-flujo-de-trabajo.md` y `06-ramas-y-pull-requests.md`.
